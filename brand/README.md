# SanjeevniOS logo

The mark is a heart-shaped leaf: the *sanjeevani* herb that brings back life,
drawn in the shape of the betel and peepal leaves known across India. The leaf
is indigo, the colour of the patient app; the stem is emerald, the colour of the
clinic console.

The SVG files here are the masters. Everything else (PNGs, app icons, web
icons) is exported from them. The wordmark is Plus Jakarta Sans ExtraBold
(SIL Open Font License), already converted to outlines, so no font is needed.

## Files

| File | Use it for |
| --- | --- |
| `sanjeevnios-logo.svg` | The logo on white or light backgrounds |
| `sanjeevnios-logo-white.svg` | The logo on indigo, emerald or dark backgrounds |
| `sanjeevnios-logo-stacked.svg`, `-stacked-white.svg` | Square spaces: splash screens, posters, social profiles |
| `sanjeevnios-mark.svg` | The leaf alone, when the name is already on screen |
| `sanjeevnios-mark-white.svg` | The leaf alone on dark backgrounds |
| `sanjeevnios-mark-mono.svg` | One-colour printing, stamps, embossing (change the fill) |
| `sanjeevnios-mark-small.svg` | Below 28 px (favicons): the veins would blur, so this has none |
| `sanjeevnios-app-icon.svg` | The app icon; full square, because the stores round the corners |
| `png/` | Ready-made PNGs, including the App Store icon (1024), Play Store icon (512) and Play Store feature graphic (1024 x 500) |

The app's icon and splash sources for Capacitor are in `/assets`. The web
icons, favicon and share image are in `/public`.

## Colours

| Name | Hex | Where |
| --- | --- | --- |
| Indigo | `#3B5BDB` | Brand colour; the leaf runs `#4C6BE8` to `#2B45AE` |
| Emerald | `#10B981` | The stem; "OS" fades from indigo to emerald |
| Mint | `#6EE7B7` | The stem on dark backgrounds |
| Ink | `#111827` | "Sanjeevni" on light backgrounds |
| App icon | `#5572EE` to `#2A3FA6` | The icon background, top-left to bottom-right |

## Using it well

- Leave clear space around the logo of at least the height of the leaf's stem.
- Keep the logo at least 96 px wide on screens (20 mm in print), and the mark
  at least 16 px.
- Don't recolour the leaf with other colours, stretch it, rotate it, add
  shadows or outlines, or put it on busy photos. Use the white version on
  colour.
- Don't re-type the name in another font. Use the files.
